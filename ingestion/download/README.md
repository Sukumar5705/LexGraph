# Ingestion — Download

Status: **PLACEHOLDER**. No downloader has been implemented and no dataset
source has been finalized yet.

Once a dataset source is selected (see `docs/methodology/` for the
in-progress evaluation of candidate sources), add scripts here to fetch
source documents, **respecting the source's terms of use/licensing** and
rate limits. Do not commit downloaded content directly — it belongs in
`data/raw/` (git-ignored).
